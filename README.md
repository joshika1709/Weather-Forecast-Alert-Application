# 🌦 Weather Forecast & Alert Application

## 📌 Project Overview

The Weather Forecast & Alert Application is a Python-based project that analyzes historical weather data to predict future weather conditions for a selected city and date.

The project focuses on:
- weather forecasting
- weather trend analysis
- alert generation
- graph visualization

Users can enter:
- city name
- future date

The system predicts:
- temperature
- humidity
- wind speed
- rain possibility

The project also generates alerts for extreme weather conditions and visualizes weather trends using graphs.

# 🔑 API Setup Instructions

Optional weather API integration can be added using OpenWeatherMap API.

## 1️⃣ Install requests library

```bash
pip install requests
```

## 2️⃣ Create .env file

```text
API_KEY=your_api_key_here
```

## 3️⃣ Generate API Key

Visit:
https://openweathermap.org/api

Create account and generate API key.
